관제 룰셋

에이전트별 로그 조건을 공격 가설과 점수로 연결합니다.

메인에이전트 관리상관분석

등록된 관제 호스트를 에이전트로 사용합니다. 룰은 수신 HOST IP에만 적용되며, SRC/DST는 조건으로 지정합니다. 탐지 점수는 일치한 룰의 합계이며 공격 확정 여부를 뜻하지 않습니다. 저장·수정 후 기존 로그도 현재 활성 룰로 다시 평가합니다.

룰과 에이전트를 불러오는 중입니다.
룰셋 추가조건 → 추정 공격 → 점수 → 판단 이유
로그 조건
포함 또는 정확히 일치, 대소문자 구분 없음. 최대 8개.

1회이면 단일 로그를 평가합니다. 2회 이상이면 해당 로그 발생 시각까지의 시간창에서 같은 에이전트·묶음 기준·조건을 만족한 횟수를 셉니다. 이후 로그를 과거 판정에 포함하지 않습니다.
